# raoulius/homebrew-tap

Homebrew casks for [MouseSnap](https://github.com/raoulius/mousesnap).

```bash
brew install --cask raoulius/tap/mousesnap
```

Update with `brew upgrade --cask mousesnap`, or along with everything else via `brew upgrade`.

The cask is bumped automatically by the [Bump MouseSnap](.github/workflows/bump.yml) workflow within 6 hours of a new MouseSnap release.
